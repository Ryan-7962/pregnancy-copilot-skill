## v0.2.1 发布门禁

- [ ] 本地全量测试通过。
- [ ] 单用户、Host Runtime、通道和合成案例验收通过。
- [ ] 干净发布目录通过隐私扫描。
- [ ] ZIP 解压后使用外部虚拟环境重新安装并跑完整测试。
- [ ] 最终 ZIP 不含缓存、私有目录、真实语料或本机路径。
- [ ] GitHub main、`v0.2.1` tag 和 Public Alpha Release 发布。
- [ ] 下载 GitHub 资产并验证 SHA256 与本地一致。

## 暂不扩展

- 独立 App、复杂 GUI 或云数据库。
- 默认微信、飞书或其他专属通道业务逻辑。
- 医生端、诊断、处方或完整自动 OCR。
- 自动伴侣共享和无需技术配置的消费级安装器。
