# PRD：Pregnancy Copilot Skill v0.1

## 1. 背景

孕期用户，尤其是第一次怀孕的孕妇，会高频产生大量问题：

- 今天肚子有点紧，正常吗？
- 胎动少了一点怎么办？
- 这个检查报告数值是什么意思？
- 这个东西能不能吃？
- 明天产检我要问医生什么？
- 我很焦虑，会不会影响宝宝？

传统路径是百度、小红书、群聊、挂号、问医生，但存在信息碎片、非个性化、非实时、无法长期记忆的问题。用户已经通过 Gemini 手机 App 和网页版进行了高强度孕期 Q&A，并通过 Chrome 插件导出 markdown、NotebookLM 汇总、Obsidian 存储孕检记录，验证了真实高频需求。

## 2. 项目定位

Pregnancy Copilot Skill 是一个以孕期 Q&A 为入口、以本地结构化记忆为核心、以消息通道为入口的孕妇专属 Agent Skill。

它不是“AI 医生”，而是：

- 类问诊式 Q&A 支持
- 医学事实记录与追溯
- 风险分级与就医提醒
- 产检前问题准备
- 孕期回忆生成
- 可选的伴侣关心建议和家庭协作

## 3. 目标用户

### 3.1 直接用户

- 孕妇本人
- 已使用 Gemini / ChatGPT / DeepSeek 等问答工具但觉得长期记忆不足的用户

孕妇本人是第一用户和数据所有者。

### 3.2 配置者

- 有一定技术兴趣的伴侣、家人或用户本人
- 已使用 OpenClaw / Hermes Agent / Claude Code / Codex / WorkBuddy 等 Agent 工具的人
- 可以完成飞书机器人、Docker、本地文件或 Git 仓库基础配置的人

配置者不等于数据管理员。即使伴侣、家人或 Hermes/Hermes 帮忙安装，也不默认获得完整孕期原文读取权。

## 4. 核心价值

1. **比普通 AI 问答更懂这一位孕妇**  
   自动结合孕周、历史孕检、医生医嘱、最近症状、情绪模式回答。

2. **Q&A 驱动记录**  
   用户不需要为了填表而填表，系统从日常问答中自动沉淀日志。

3. **医学安全边界更明确**  
   内置红黄绿风险分级和红旗症状库。

4. **孕期数据长期可迁移**  
   数据与代码分离，原文、事件、摘要、作品分层保存。

5. **回忆价值**  
   通过宝宝视角周记、孕期回忆录，将健康数据和生活片段转化成长期可保存的记忆作品。

6. **可选协作**  
   如果孕妇明确开启共享，可生成伴侣 summary 或家庭协作素材；这不是 v0.1 默认主路径。

## 5. 非目标

v0.1 不做：

- 替代医生诊断
- 医生端协作
- 自动给医生发消息
- 复杂 App 或网页后台
- 微信默认适配
- 完整多飞书机器人邀请/授权流程
- 国际版产检流程
- 云数据库默认部署
- 所有检查报告 OCR 自动识别
- 复杂体重/血糖图表

## 6. MVP 范围

### 6.1 必须包含

1. 飞书一对一孕期 Q&A
2. 当前孕周和基础档案读取
3. 红黄绿风险分级
4. 医学风险问题的短声明
5. 原始消息写入 inbox
6. 结构化事件写入 events.jsonl
7. current_context.md 自动更新
8. 每日健康摘要
9. 每周宝宝视角日记
10. 本地备份
11. schema_version
12. 支持通过 `lark-cli --profile` 指定孕妇聊天 bot 所属飞书 app/profile

### 6.2 可选包含

- Gemini/NotebookLM/Obsidian 历史导入器雏形
- 飞书多维表格 schema 草案
- 体重/血糖/用药事件类型定义
- 伴侣 summary 日报
- 老婆确认后同步机制
- `#爸爸日记` 写入本地与飞书文档
- 飞书文档标题规范

## 7. 用户角色与模式

### 7.1 默认模式：孕妇模式

触发方式：孕妇用户私聊机器人。

功能：

- 孕期 Q&A
- 症状分级
- 饮食/运动/用药/检查报告解释
- 情绪安抚
- 私密记录
- 可选同步权限控制

### 7.2 可选扩展：伴侣模式

触发方式：孕妇明确启用共享后，伴侣用户私聊机器人或同一 host Agent 的另一个入口。

功能：

- 查看 summary 版日报
- 写入 `#爸爸日记`
- 触发 `#宝宝日记`
- 查看产检问题清单
- 查看可共享事项

伴侣模式只能读取孕妇允许共享的信息。默认不共享原文。

### 7.3 可选扩展：夫妻群模式

触发方式：夫妻群内 @机器人。

功能：

- 共同产检准备
- 共享提醒
- 明确同意后的信息同步

### 7.4 宝宝日记模式

触发方式：定时每周生成或手动 `#宝宝日记`。

功能：

- 从本周健康摘要、老公日记、孕周发育科普中生成宝宝视角周记
- 禁止医学暗示

## 8. 核心 Q&A 工作流

1. 接收消息
2. 判断用户身份和模式
3. 判断问题类型：症状 / 饮食 / 用药 / 报告 / 情绪 / 产检 / 运动 / 胎儿发育 / 日记
4. 构建上下文：读取 profile、current_context、最近日志、相关报告、红旗规则
5. 风险分级
6. 生成回答
7. 写入 inbox 原文
8. 写入 events.jsonl 结构化事件
9. 必要时更新 doctor_questions
10. 每日/每周生成摘要和作品
11. 如孕妇明确开启共享，再生成伴侣可见摘要

## 9. 成功标准

v0.1 成功不以功能数量衡量，而以以下标准衡量：

- 孕妇可以自然在飞书里连续问问题
- Agent 能稳定读取当前孕周和关键历史背景
- 对医学风险问题不会轻描淡写
- 每次问答都能沉淀为可迁移事件
- 非医学闲聊不会被强行红绿灯化
- 医学状态更新后，最新有效值优先于历史旧值
- v0.2 可读取 v0.1 全部记忆并迁移
