# Decision Log

## D001 - 项目名称

通用项目不使用任何私有孕妇昵称命名。真实昵称仅作为用户自己的本地 profile 名称。

## D002 - MVP 入口

MVP 以孕期 Q&A 为入口，不以手动日志为入口。日志是 Q&A 的后台副产品。

## D003 - 消息通道

MVP 默认支持飞书机器人应用。

## D004 - 机器人策略

MVP 采用单飞书机器人、多身份、多模式设计，不依赖多个飞书机器人。

## D005 - 存储策略

默认本地 Markdown + JSONL 保存，不默认云数据库。

## D006 - 原文保存

原文完整保存到 inbox，但日常回答不全量读取原文，只读取摘要、事件和相关索引。

## D007 - 记忆迁移

v0.1 必须支持 schema_version、append-only events、升级前备份、摘要再生成。

## D008 - 老公共享

默认只发送 summary，不同步完整原文。完整同步需要孕妇确认。

## D009 - 宝宝日记

宝宝视角日记作为创意写作，不允许产生医学暗示，不得承诺宝宝健康。

## D010 - 红旗症状库

必须内置红旗症状库，作为安全底线，不完全依赖模型自由判断。

## D011 - 模型策略

Skill 不绑定具体 LLM。默认使用宿主 Agent 自带模型。医学类任务建议使用最强可用模型。

## D012 - 中国流程优先

v0.1 默认按中国大陆主要妇产科医院流程设计。国际版后置。

## D013 - 飞书文档

飞书文档/多维表格作为展示层，不作为主数据源。

## D014 - Family Memory

老公孕期日记、宝宝视角日记、回忆录素材进入项目，但作为可选作品模块。
