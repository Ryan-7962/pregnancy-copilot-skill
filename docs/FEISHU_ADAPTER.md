# Feishu Adapter：飞书适配设计

## 1. MVP 策略

v0.1 默认支持飞书机器人应用。

不默认支持：

- 多飞书机器人
- 多 Agent 多机器人复杂路由
- 微信
- 国际消息通道

采用：

```text
单飞书机器人
单 Agent
多身份
多模式
```

## 2. 消息模式

### 2.1 孕妇私聊

默认进入 Pregnancy Q&A Mode。

示例：

```text
今天肚子有点紧，正常吗？
```

### 2.2 可选：伴侣私聊

默认进入 Dad Mode。

示例：

```text
#爸爸日记 今天陪她去产检，她很紧张，但看到宝宝后开心了很多。
```

### 2.3 夫妻群

默认进入 Couple Coordination Mode。

示例：

```text
@机器人 明天产检帮我们整理一下要问医生的问题
```

### 2.4 命令路由

```text
#爸爸日记
#宝宝日记
#今日总结
#产检问题
#不同步
#可同步
#只同步建议
#完整同步
#导出
#备份
```

## 3. 飞书文档写入

飞书文档作为展示层，不作为主数据源。

### 3.1 可选：爸爸孕期日记标题规范

标题必须包含：

```text
W{孕周}+{天数}｜心情：{当天孕妇心情}｜宝宝状态：{宝宝状态}
```

示例：

```text
W20+0｜心情：紧张转安心｜宝宝状态：稳定成长
```

注意：宝宝状态不能做医学暗示。可使用“继续成长”“今天被认真记录”“等待下次产检确认”等非医学表达。

### 3.2 文档内容结构

```markdown
# W20+0｜心情：紧张转安心｜宝宝状态：继续成长

## 爸爸原文

...

## AI 整理版

...

## 今日照片

...

## 可选宝宝视角

...
```

## 4. 飞书多维表格

v0.1 可以先不实现，但建议 schema 预留：

- 产检日历
- 待问医生问题
- 用药提醒
- 体重记录
- 血糖记录
- 红黄绿事件列表

## 5. 同步策略

```text
本地 events / memory
↓
生成 daily_log.md / diary.md / baby_diary.md
↓
同步到飞书文档
```

飞书写入失败时，不应影响本地数据保存。

## 6. 隐私同步

伴侣日报不是 v0.1 默认主路径。只有孕妇明确开启共享后，才发送经过过滤的 summary。

可选指令：

```text
#不同步
#只同步建议
#可同步
#完整同步
```

完整同步必须由孕妇确认。

## 7. 后续消息通道抽象

建议保留 adapter 抽象：

```text
message_adapters/
├── feishu.py
├── telegram.py
├── wechat.py
├── email.py
└── cli.py
```

v0.1 只实现 Feishu。
